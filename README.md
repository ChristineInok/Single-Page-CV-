Single-Page CV

A simple, semantic, single-page Curriculum Vitae (CV) built with HTML as part of the [roadmap.sh Frontend Developer Projects](https://roadmap.sh/projects/single-page-cv).

Project Overview

This project involves creating a single-page CV using HTML. The goal is to practice structuring web content with semantic HTML elements and organizing personal and professional information in a clear, readable format.

The CV presents essential information about an individual, including contact details, education, skills, and work experience.
